# 2084 mode — design (Build B)

Date: 2026-09-29. Companion to the Oracle 2084 spec in the `oracle-2084` repo.

## Purpose

A button on the outer 3D scene switches the Macintosh between 1984 (today's
daylight scene, System 7 site inside) and 2084 (blackout, neon relight, the
oracle terminal at https://2084.diaoev.com inside). The transition itself is
the creative moment: lights off, then the neon flickers on.

## Decisions

- Mode state `'1984' | '2084'` in App, passed down as props. No store.
- Trigger: pixel-style overlay button bottom-left, `▶ 2084` / `◀ 1984`,
  disabled while switching. 1984 is the hardware year; the OS inside is
  System 7, and that is fine.
- No new 3D assets. The existing lights, sky and materials are re-tuned.
- Post-processing (`@react-three/postprocessing`): bloom, slight chromatic
  aberration and a faint scanline pass, mounted only in 2084 mode. Phones
  get bloom only at reduced resolution.
- Iframe sources: `VITE_IFRAME_WEBSITE` (1984) and `VITE_IFRAME_WEBSITE_2084`.
- Mode is not persisted across reloads. No sound.

## Transition to 2084

| t | event |
|---|---|
| 0.0 s | all lights → 0 over 0.4 s; background → black; screen div covered black |
| 1.2 s | cyan point light stutters on (two flickers, then holds); effects mount |
| 1.6 s | magenta point light does the same; violet ambient rises slowly; model emissive edges rise |
| 2.2 s | screen glitch (scanline tear + red/cyan split, 1.2 s); iframe src swaps at its midpoint |
| 3.0 s | button re-enabled |

## Transition to 1984

Neon snaps off, ~1 s dark, daylight fades up over 1 s, screen glitch with the
OS site returning, effects unmount at the start.

## Palettes

1984: today's values in SceneLighting. 2084: ambient deep violet `#3b1f6e`
low; main light off; fill `#0088ff` low; rim off; spot cool white low; point1
magenta `#ff00ff` and point2 cyan `#00ffff` at high intensity; background
gradient `#05030a` → `#1a0b2e`. Model: non-screen meshes colour toward
`#1c1a22`, emissive cyan `#00ffff` at ~0.15.
